Core 폴더는 사용자가 작성하는 어플리케이션과 STM32 하드웨어 사이의 연결점이다. 

Core/Inc에는 헤더파일이 있고 
함수 선언
매크로 정의
핀 정의
를 보관한다.

Core/Src에는 실제 코드가 있다.

startup이 실행될때 SystemInit()은 Core의 소스에 있다.
cubemx에서 USART,DMA,GPIO설정등을 하면 generate code 시 관련함수가 생성되고 함수호출은 main.c에 들어간다.

main.c에 호출된 함수는 보통 정의또한 함께 있으며, 그 함수의 로직중에 Driver내부에 정의된 함수가 호출된다. 
Driver영역에는 HAL_로 시작하는 함수들이 정의되어 있다.

Core : 애플리케이션 계층, 어떤 명령/동작을 내릴지 지시
Driver : 하드웨어 제어 계층, 명령/동작을 구현하는 방식을 정의
즉 Core->HAL->레지스터->하드웨어

그러나 Driver가 항상 Core에게만 호출되는 것은 아니다. Core와 Driver는 양방향 상호작용한다.
Core
 ├─ main.c
 ├─ system_stm32f4xx.c
 ├─ stm32f4xx_it.c
 └─ stm32f4xx_hal_msp.c

        ↑
        │
        │ 호출
        ↓

Drivers
 ├─ stm32f4xx_hal_uart.c
 ├─ stm32f4xx_hal_gpio.c
 ├─ stm32f4xx_hal_dma.c
 └─ ...

 + hal(Hardware Abstraction Layer), 하드웨어를 쉽게 사용하기 위한 중간 계층이다.
 GPIO출력을 설정한다고 했을 때, 레지스터를 직접 조작하는 방법 대신 정의된 HAL라이브러리를 사용하여 레지스터를 설정하는 것이다.

 ex) 레지스터 직접 접근 방식
 RCC->AHB1ENR |= (1<<0);

GPIOA->MODER &= ~(3<<10);
GPIOA->MODER |= (1<<10);

ex) HAL방식
GPIO_InitTypeDef GPIO_InitStruct;

GPIO_InitStruct.Pin = GPIO_PIN_5;
GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;

HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
